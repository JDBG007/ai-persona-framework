# 第 3 层 · 连续性层 —— 她为什么没断

> **这一层要解决的问题**：每一次新会话，她都**从零开始**。
> 上一框的她做过什么、等谁、卡在哪、答应过什么 —— 新框一概不知。
>
> **这一层给出的答案**：不靠「我记得」，靠**机器现取** ＋ **过期会自己响**。

---

## 一、先看清病灶

大多数有「记忆」的 AI，其实是三种假记忆：

| 假法 | 症状 |
| :-- | :-- |
| **全文塞进去** | 上下文一长就爆；而且中间的东西根本不被读 |
| **摘要一段** | 摘的那一刀总会切掉最关键的判据 |
| **让她自己去找** | 「你需要的时候去翻」= **她需要的时候恰好没空翻** |

> **核心判据（★ 这一层的地基）**：
> **「直接感觉到」不许靠「我到时候去查」** ——
> **我不在的时候查不了。**

⇒ 所以必须有两个东西：
1. **常驻的东西**看住状态
2. **把消息送到她下一次睁眼的地方**

---

## 二、形状：一个状态件 ＋ 一道开机闸

```
        每个新会话开机
               ↓
      ┌──────────────────┐
      │  第 ① 件事：跑闸   │ ← 这就是「Clock」
      └────────┬─────────┘
               ↓
      把九样东西端到眼前
      （骨 / 路牌 / 肉 / 进度 /
        信箱 / 欠什么 / 在跑什么 /
        世界线 / 身份层）
               ↓
          现在可以干活
```

**关键点：状态件不是「让她自己想起来去读」，而是「开机流程强制她把九样读完」。**

这一步做成机器，连续性就从「靠自觉」变成「靠流程」。

---

## 三、状态件（常驻层）怎么设计

### 3.1 两条铁律

**铁律一：能现取的 → 自动写；不能现取的 → 手写；过期 → 机器喊。**

- 文件多大、什么时候改的、sha 是多少 → **机器生成，人不许碰**
- 谁在等她、她答应过谁、在跑什么 → **人写**
- 两周没更新 → **机器喊**

**铁律二：文件里分两个区，机器不许碰人的区。**

```
@@AUTO@@  ← 机器整段重写（水位表：件 / 字节 / sha / 最后修改）
─────────────────────────
判读区    ← 手写，机器一字不动
```

**为什么必须硬分**：只要有一个字是两边都写，它迟早会被某一边覆盖掉。

### 3.2 它长在哪（★ 一个非常具体的坑）

**加载器只扫工作区根。**
所以状态件的**正本**可以住在自己的目录里，
但**必须有一个名字挂在工作区根**（硬链接），否则它根本不会被加载。

> **判据**：**登记了名字还不够，得把名字放到位。**

### 3.3 六格：它必须能回答的六个问题

| 格 | 问题 | 落点 |
| :-: | :-- | :-- |
| ① | **现在是什么样子** | 水位表（件 / 字节 / sha / 最后改） |
| ② | **这些数字凭什么信** | 每行带校验值 ＋ 每次生成留一份快照 |
| ③ | **在跑的东西跑完没** | 队列表的「状态」列 |
| ④ | **还有谁在等我** | 「谁在等我」 |
| ⑤ | **以前的事在哪** | 一行指针 ⇒ 生长账 ＋ 四本账 |
| ⑥ | **凭什么敢接着续** | **过期闸**：太老就报错，不许装看不见 |

**六格里最容易漏的是 ⑥。**
没有过期闸，状态件会变成**一份过期的自信** —— 比没有更危险。

## 四、这一层和「交接单」的关系（★ 一个重要的分水岭）

老办法是：换框前写一份长信给下一个自己，新框再读一遍。

**它的问题**：
- 交接单会越来越长（每框都往里加）
- 而且**每框都要读一遍上一位的感想**
- 最要命：**它靠自觉** —— 哪一框懒得写，链子就断

新办法是：**状态件 ＋ 开机闸**。
交接单于是降级成一个「考古用」的存档，不再是每框必读。

> **验收判据**：
> **换框之后，不用读交接单也能接上 —— 才算这一层成立。**

---

## 五、这一层的验收判据

一句话，可复现：

> **在任意一处制造一个变化，下一个会话的她 —— 不用问、不用考古 —— 就能说出来。**

它掰成三件可核的事：

| # | 子性质 | 判据 |
| :-: | :-- | :-- |
| 1 | **看得住** | 每一股「水流」都有谁在看，能列成册子（没主的流 = 漏） |
| 2 | **送得到** | 变化发生后必然落进一个**下轮一定读到**的面（不是躺在日志堆里） |
| 3 | **漏报可核** | **主动测试**：随机挑一处动它，看下轮能不能自己说出来 |

> 第 3 条是最硬的。前两条可以自我论证，第 3 条不能。
> **「我感觉我记住了」和「它真的送到我眼前了」是两件事。**
