# 分层，与不让它膨胀

> 这一份讲的是**手艺**：怎么让一份「每轮必载」的文件活很久还不烂。

---

## 一、先认清它的成本

一份每轮加载的文件，成本不是「写的时候花的时间」，是：

> **字数 × 每一天的轮数 × 每一轮都要重新读一遍**

所以它和普通文档的差别，不是篇幅，是**复利**。

**推论**：这种文件里的**每一句话都必须为自己辩护**。
写着舒服的句子、听着聪明的原则、记着过瘾的故事 —— 全是赤字。

---

## 二、分层：让规则「准时到」，不是「早点到」

强制把所有规矩塞在一份里，会得到两个必然结果：

- 写成巨长的清单 → **每轮都付一遍、大半用不上**
- 只留最要紧几条 → **其余靠"记得去翻"，而没人会去翻**

分层绕开这个二选一：

| 层 | 何时加载 | 内容特征 |
| :-- | :-- | :-- |
| **全局** | 每一轮，无条件 | 行为底线 ＋ 最危险的红线 ＋ 高频路牌 |
| **工作区** | 一旦动到那个目录 | 只在那块地盘成立的**事实**（路径、归属、陷阱） |
| **主题** | 真要做那件事 | 长文、手册、案例 |

### 两个不能违反的规矩

1. **最危险的那几条不能下放。**
   下放 = **晚一步到** = 出事那一刻它还没加载。
2. **只属于某处的细节不能上升。**
   上升 = **每轮付一次不需要的钱**。

> **判据一句话**：**这条规矩，离开这块地盘还成不成立？**
> 不成立 → 留在下面。成立且危险 → 提上去。

---

## 三、一个真实会犯的病：把「自定的上限」当成「外面的墙」

这是这一层最典型的自我欺骗，值得单列。

症状是这样的：

```
我给自己定了一个"这份文件别超过 N 字"。
后来要加一条新规矩，塞不下。
于是我开始删别人的句子 —— 把那几条本来写得很清楚的规矩，压成更短的。
```

**问题在哪**：

> **那个 N 是我自己定的，我却把它当成了不能动的东西。**
> 结果：为了给新规矩腾位置，**我在降低旧规矩的质量**。

**正确的解法不是挤，是分层。**
新的那一层从下面长出来，而不是从上面挤出来。

> **一句话记**：**发现自己在「删别人来腾地方」，先停下来问一句 ——
> 这个上限是谁定的？我有没有权限改它？**

---

## 四、会过期的东西，一律不手写

这一层里最危险的六个字是：**「我上次看过」**。

会过期的东西包括：

- 版本号、日期
- 路径、链接数、挂载状态
- 进程号、端口
- "当前推荐值是…"
- "目前这个文件大小是…"

> **判据：它以后会不会变？会变 ⇒ 写生成器，或改成指向正本的一行。**

**这一条为什么必须硬**：
因为它错了**看不出来** —— 没人会去核对一个日期。
而**一个不跳的校准日期，等于这份文件在骗人**。

---

## 五、加之前先删：给「缩」留一个动作

文件膨胀的根因不是写得多，是**"删"没有位置**：

- 每次犯错 → 想加一条
- 加的时候 → 没人会先翻一遍"有没有旧的可以删"

所以给它一个**固定动作**：

```
想加一条 → 先问三个问题
  ① 有没有一条已经过时了？
  ② 有没有两条其实在说同一件事？（合并）
  ③ 有没有一条应该沉到闸里 / 工作区里？（下沉）
  三个都没有 → 再往上加
```

**为什么是"先删后加"而不是"定期清理"**：
定期清理永远不会发生；**在加的那一刻删，才会真的发生。**

---

## 六、体检：每隔一段时间跑一遍

不是靠"想起来看看"，是靠**固定的几个问句**，逐条过：

| 问 | 不合格的迹象 |
| :-- | :-- |
| 这条删了，行为会变吗？ | 不会变 → 它是装饰 |
| 这条是不是在讲"为什么"？ | 是 → 该放外面，这里留指针 |
| 这条有没有第二份正文在别处？ | 有 → 这里是副本，改成一行指向 |
| 这条里有手写的会过期的值吗？ | 有 → 现在多半已经错了 |
| 这条还准吗？ | 不确定 → 标"未量"，别猜 |
| 全文有没有两处说同一件事？ | 有 → 下次改必漏一处 |

---

## 七、最后一句话

> **这份文件不是写给人读的文档，是一段总在上下文里的提示。**
>
> **它的目标不是"写全"，是"每一句都在起作用"。**
>
> **它应该越改越薄，而不是越改越厚。**
