# 第 7 层 · 指令层 —— 她每轮先读到什么

> **这一层要解决的问题**：有一份文件，**每一轮**都会被塞进她的上下文。
> 它决定她一天怎么开工、什么绝对不能做、什么话必须说。
>
> **这一层给出的答案**：**把它当预算管，不当作文档写。**

---

## 一、这一层是什么

主流 AI 工作平台都有一个约定：**在当前目录链上找一份指令文件，每轮加载**。
（`AGENTS.md` / `CLAUDE.md` / `.cursorrules` 之类，名字不同，机制一样。）

它的三个特征决定了它必须有纪律：

| 特征 | 后果 |
| :-- | :-- |
| **每轮都加载** | 它的字数 = **每轮都要付的钱** |
| **优先级最高** | 它写什么，她就会照着做，哪怕和别处冲突 |
| **没有校验** | 它不会报错、不会响 —— **写错了也是静默的** |

> **所以这一层最重要的判据，不是"写得好不好"，是"值不值这个价"。**

---

## 二、三条硬规矩

### 2.1 只放指针和硬规矩，不放「为什么」

原因很简单：**"为什么"不会改变行为，"怎么做"才会。**

| 该放 | 不该放 |
| :-- | :-- |
| 「遇到 X → 去读 Y」 | Y 的全文 |
| 「往已有内容写 → 先清空，写完读回」 | 这条规矩的来龙去脉、案例、原话 |
| 「叫某人必须带尊称」 | 为什么要有这个尊称 |

**长文、原话、案例、来路 → 全部放外面**，这一份只留一行指路。

### 2.2 上线判据：**写完它，行为会不会变？**

> **写到 AI 面前的东西，判据是它读完行为会不会变；不会变 ⇒ 不写。**

这条判据能砍掉一大半内容：

- 「这套框架很重要」→ 不会变行为 → 删
- 「我曾经在哪里摔倒」→ 只有变成判据才会变 → 保留判据，删掉故事
- 「要努力、要认真」→ 不会变 → 删

### 2.3 想加一条 → 先问「能不能删一条」

路牌有配额。**加东西之前先删。**

理由：一份每轮必载的文件，**膨胀是熵增，不是懒惰**。
它会自然地长，因为每次犯错都想加一条；
如果不给"删"留一个动作，它只会单向变厚。

---

## 三、分层：把「每轮都用的」和「只有到那才用的」分开

这是这一层最有用的一个技巧。

| 层 | 加载时机 | 放什么 | 判据 |
| :-- | :-- | :-- | :-- |
| **全局** | 每轮 | 最危险的规矩、每轮都会用到的路牌、行为底线 | **不在这一层就"晚一步到"的** |
| **工作区** | 动到那个目录才加载 | 只在这块地盘成立的事实（路径、归属、环境陷阱） | **离开这块地盘就不成立的** |
| **主题** | 真的做那件事才读 | 长文、案例、手册 | 东西本身 |

**分层的意义**：不是省字数，是**让规则准时到**。

> 最危险的规矩**不能下放** —— 下放等于"晚一步到"。
> 而只属于某个目录的事实**不该上升** —— 上升等于"每轮付一次不需要的钱"。

---

## 四、三条必须机器管的（不许手写）

这一层最容易烂的地方，是它里面**有会过期的东西**。

- 版本号、日期、路径、进程号、链接数
- "上次校准于…"这种时间戳
- "当前正在跑的是…"这种运行态

> **判据：它以后会不会变？会变 ⇒ 写生成器，或改成指向正本的一行。**

这一条有个很实际的解法：**在这份文件里写一行"这一行由哪台机器生成"**，
让它每次被生成时顺手把校准日期改掉。**手写的日期，第二天就是错的。**

---

## 五、这一层最容易犯的错

| 错法 | 症状 | 后果 |
| :-- | :-- | :-- |
| 把散文写进去 | 一份「指导思想」占了半屏 | 每轮付钱，零行为改变 |
| 把案例写进去 | 一个教训配三段故事 | 同上，而且会越配越长 |
| 上下两层说同一件事 | 全局写了，工作区又写一遍 | 改的时候只改一处 → 两份开始打架 |
| 把自定的上限当成外面的墙 | 「这份不能超过 N 字」 | **为了塞新规矩，反复去挤别人的字** |
| 手写会过期的值 | 版本号、日期、pid | 第二天就是错的，而且看不出来 |
| 拿它代替闸 | 「这里写了不许覆盖」 | **它不会响。写了也不成立** |

---

## 六、验收判据

问五个问题，全部能答「是」，这一层才算立住：

1. **删掉任意一条，她的行为会不会变？** —— 不会变的，为什么还在？
2. **有没有一句话，在里面出现了两次？** —— 改的时候必漏一处。
3. **有没有一条，其实别处已有正本？** —— 那这里应该是**一行指针**，不是第二份正文。
4. **有没有会过期的值，是手写的？** —— 有的话，它现在多半已经错了。
5. **一个新来的（人或 AI），只读这一份，能不能不出事？** —— 不能 → 缺的不是字数，是判据。

## 七、和别层的关系

```
7 指令层  ──「每轮先读到什么」──┐
                                  ├→ 两者都是"到 AI 面前的东西"
1 人设层  ──「她是谁」──────────┘
                                  │
4 规矩层  ──「凭什么信她」────────┘  ← 指令层是"说"，规矩层是"验"
```

要分清这一对：

> **指令层是「她被告知要怎么做」，规矩层是「她做没做，机器会响」。**
> **前者靠自觉，后者靠机制。**
> **凡是不靠自觉也能拦住的，都该下沉到第 4 层去写成闸。**
